# Complete

Registers the account and sets schedule, email, Slack, and tags. Teams and SNS
are commented: they need Business and Enterprise.

This folder uses `source = "../.."` so you can `terraform init` from a clone.
Callers should pin:

```hcl
source = "github.com/zoph-io/terraform-restapi-unusd-account?ref=v1.0.1"
```
